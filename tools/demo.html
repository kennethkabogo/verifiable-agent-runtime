The resulting evidence bundle is independently verifiable by anyone: no access to the enclave, no trust in the operator.

What this proves
01 — integrity
Computation is tamper-evident
The decision was computed exactly as logged. The L1 hash chain — SHA-256 folded at every step — means any alteration breaks every subsequent hash and signature.
02 — hardware
Silicon root of trust
In production, signatures are issued by AWS Nitro silicon. PCR measurements pin the exact binary that ran — no operator can swap the code without breaking the attestation.
03 — auditable
Zero-trust verification
Any counterparty can run apex_verify.py against this bundle — no enclave access, no trust in VAR, no call to any VAR infrastructure. The math is the auditor.
